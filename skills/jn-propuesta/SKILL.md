# Propuesta comercial (ejemplo de skill del pack)

> Skill de ejemplo: sustitúyela por las tuyas. Muestra cómo una skill común usa el material del pack y, si existe,
> el del cliente.

1. Lee `mi-negocio/pack/metodologia.md` (cómo trabaja Juanan) y, si existe, `mi-negocio/pack/empresa.md`
   (quién es este negocio, qué vende y a qué precios).
2. Pregunta solo lo que falte, de una en una: para quién es, qué problema tiene y qué presupuesto o plazo maneja.
3. Escribe la propuesta con esta estructura: situación, objetivo medible, qué se hace (fases), plazos, inversión y
   siguiente paso. Usa el tono de `empresa.md` si lo define.
4. Nunca inventes precios ni resultados: si `empresa.md` no los trae, deja el hueco marcado y díselo.
